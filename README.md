# Simple Ecommerce Application

A simple ecommerce application created as a learning project to better understand how to build modern React applications using Vite and browser local storage.

## Features

- Browse products
- Add and remove items from cart
- Mock register and login
- Store user data using Local Storage
- Responsive UI
- Fast development setup with Vite

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- Local Storage API

## Deployment

The website is live on Vercel:

[Live Demo](https://ecomm-app-blond.vercel.app/)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Adamooy/ecomm-app.git
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

## Learning Goals

This project was built to practice:

- React component architecture
- State management
- Working with Local Storage
- Project structure in Vite
